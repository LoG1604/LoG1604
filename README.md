### :rocket: Featured Projects

#### :chart_with_upwards_trend: Churn Intelligence (in progress)
End-to-end customer churn analysis on the Online Retail dataset. Cleans data with SQL, builds RFM features, predicts churn, explains the model and turns results into actions inside a dashboard.

- **Pipeline:** DuckDB SQL cleaning, RFM analysis, churn labeling
- **Modeling:** XGBoost for prediction, SHAP for explaining why customers leave, KMeans for segments
- **App:** Streamlit dashboard with LLM-generated retention suggestions

`Python` `DuckDB` `SQL` `XGBoost` `SHAP` `Streamlit` `Pandas`

[View repo](https://github.com/LoG1604/churn-intelligence)

> Dashboard screenshot coming soon

#### :briefcase: Quorum
Job application tracker built as a SaaS. Aggregates listings from multiple job APIs, tracks every application and keeps each user's API keys encrypted.

`Next.js` `Supabase` `Upstash Redis` `Vercel`

[View repo](https://github.com/LoG1604/quorum)
